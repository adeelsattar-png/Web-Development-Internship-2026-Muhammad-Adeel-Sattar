Case Study Report
Portfolio Case Study: Bella Italia Restaurant & Delivery Website
Overview
This project is a modern, responsive single-page website developed for Bella Italia, a local Italian restaurant. The objective was to build a clean and appealing digital presence where customers can explore the food menu, place online home delivery orders, and reserve tables.

Key Features & Structure
Responsive Header Navigation: Sticky navigation bar that switches to a mobile drawer menu on smaller screens.
Hero & About Section: Features high-resolution food images and background information on the restaurant's organic ingredients and traditional recipes.
Interactive Food Menu: Displayed in a card grid featuring dish photos, descriptions, prices, and direct order buttons.
Home Delivery Booking System: A structured form with JavaScript validation that allows users to pick their meal, enter delivery address, and confirm their order instantly.
Table Reservation System: Contact form with client-side validation checking required fields (Name, Email, Reservation Notes).
Technologies Used
HTML5: Semantic architecture (<header>, <nav>, <section>, <footer>).
CSS3: Flexbox layout, image grid, custom button styles, and responsive @media break points.
JavaScript (Vanilla): Event handling for mobile navbar toggling and client-side form validation.
